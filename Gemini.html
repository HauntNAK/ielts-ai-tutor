Nhập Google Gemini API Key
Gemini API hoàn toàn miễn phí, không cần thẻ tín dụng!

Cách lấy key (2 phút):
1. Vào aistudio.google.com/apikey
2. Đăng nhập Google → bấm "Create API Key"
3. Copy key và dán vào ô bên dưới

Key chỉ lưu trên máy bạn, không gửi đi đâu cả.
Chưa lấy key ngay? Vẫn dùng được Reading & Listening
